# FallGrade

**9-Dimension Portfolio Grader**

Sovereign tool for evaluating technical portfolios across 9 dimensions. 8 developer archetypes. Built for Guild recruitment pipeline.

## Features

- 9-dimension scoring: Code Quality, Architecture, Testing, Documentation, Originality, Complexity, Maintenance, Communication, AI Integration
- 8 developer archetypes: Architect, Craftsman, Scientist, Artist, Engineer, Polyglot, Specialist, Generalist
- Bloom vector visualisation per candidate
- Verdict system: GUILD READY / PROMISING / DEVELOPING / RED FLAG
- Skill gap analysis with development recommendations
- Portfolio comparison across candidates
- Multi-provider AI analysis
- All evaluation data stored locally — IndexedDB

## Run

Double-click `FallGrade.html`. Paste a portfolio. Get the grade.
